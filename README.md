# qa_python

test_add_new_book_add_two_books: Проверяет добавление двух книг и корректность их количества в коллекции (длина словаря books_rating должна быть 2).

test_add_new_book: Параметризованный тест на добавление книги с различными именами (валидное, пустое, слишком длинное), проверяет, добавляется ли книга в словарь books_genre и устанавливается ли пустой жанр по умолчанию.

test_set_book_genre: Проверяет только установку жанра (использует прямой доступ к books_genre для проверки).

test_get_book_genre: Проверяет только получение жанра (подготавливает состояние через прямой доступ к books_genre).

test_get_books_with_specific_genre: Параметризованный тест на получение списка книг по конкретному жанру; проверяет фильтрацию книг с заданным жанром и пустой список для жанра без книг.

test_get_books_genre: Тест на получение полного словаря жанров книг; проверяет, что возвращается корректный словарь с жанрами добавленных книг.

test_get_books_for_children: Тест на получение списка книг для детей; проверяет фильтрацию книг без возрастного рейтинга (т.е. не в genre_age_rating).

test_add_book_in_favorites: Параметризованный тест на добавление книги в избранное; проверяет, добавляется ли книга в список favorites для существующей книги и не добавляется для несуществующей.

test_delete_book_from_favorites: Параметризованный тест на удаление книги из избранного; проверяет удаление существующей книги и отсутствие изменений для несуществующей.

test_get_list_of_favorites_books: Тест на получение списка избранных книг; проверяет, что возвращается корректный список добавленных в избранное книг.

test_init: Тест на инициализацию объекта; проверяет начальные значения атрибутов (books_genre, favorites, genre, genre_age_rating).
